PLATE 04.3.5 — ONE VERSIONED FRONTEND, CURRENT SUPABASE

This replaces the old multi-file module loader with one JS bundle and one CSS file.
Their content-based filenames prevent old cached module dependencies from mixing.
Includes all previous UI patches and removal of hw/road/gai/evshop.

INSTALL IN TWO COMMITS (GitHub Pages main/root):
1. Upload the css and js folders from this ZIP to the repository ROOT. Commit.
   Do not delete existing js/css/img files. Wait for successful Pages deployment.
2. Upload this index.html to the repository ROOT, replacing the old file. Commit.
   Wait for successful Pages deployment again.
3. Close/reopen the Mini App and use its Reload action if still showing the old screen.
   Below the profile in the desktop sidebar / mobile workspace navigation,
   the release label should include 04.3.5.

Do NOT change SQL, RLS, grants, keys or Edge Functions.
This is the non-demo production frontend, using current server contracts.
No new anti-bot backend is installed. No automatic retries of purchases.

If errors persist, take a screenshot of the NEW error text. It includes operation,
HTTP status and error code when returned by Supabase. Do not send access tokens.
The common handler no longer claims every error is a network outage.
Permission/session/quota errors still require diagnosis; this build does not bypass them.
